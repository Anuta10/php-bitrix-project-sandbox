# Corporate Portal Sandbox — PHP / 1C-Bitrix Project Portfolio

## English

An interactive PHP portfolio focused on project-based and contract work with existing PHP / 1C-Bitrix systems.

It recreates, in an anonymized form, several types of solutions I have worked on in corporate projects: an employee directory, birthday reminders and notifications, a custom portal homepage, and Calendar-to-Tasks automation for the **Communication Support** workflow.

All employees, departments, contacts, events, and content shown in the demo are fictional. The project was implemented separately for portfolio purposes and does not contain source code, internal data, or proprietary materials from real clients.

## Русский

Интерактивное PHP-портфолио для проектной работы и отдельных заказов по существующим PHP / 1С-Битрикс системам.

В проекте в обезличенном виде воспроизведены несколько типов задач, с которыми я работала в корпоративных проектах: телефонный справочник, дни рождения и напоминания, кастомная главная, а также интеграция Календаря и Задач для сценария **«Сопровождение связи»**.

### Календарь → «Сопровождение связи» → Задача

Календарь и Задачи являются стандартными инструментами 1С-Битрикс.

В этом кейсе демонстрируется **кастомная интеграция между ними**.

Не каждое событие календаря создаёт задачу. При создании встречи пользователь отдельно выбирает **«Сопровождение связи»**, если для мероприятия требуется видеосвязь, оборудование или помощь инженера.

Только после этого запускается автоматизация:

`Событие календаря → фоновая обработка → связанная задача группы сопровождения`

В задачу передаются:

- название мероприятия;
- дата и время;
- место;
- организатор;
- участники;
- описание;
- запрос на сопровождение;
- комментарии к событию.

Если встречу перенести, изменить участников или добавить комментарий, обновляется **та же связанная задача**, а новая не создаётся.

После создания или обновления задачи возле пункта **«Задачи»** появляется индикатор непросмотренных изменений.

Техническая часть очереди и повторной обработки не вынесена в основное меню. Она доступна на странице **«Как работает автоматизация»**.

## Демо остаётся актуальным со временем

Данные, для которых важна текущая дата, рассчитываются относительно сегодняшнего дня.

Динамически обновляются:

- дни рождения;
- встречи;
- сроки связанных задач;
- отпуска;
- даты новостей;
- записи Живой ленты;
- время демонстрационных уведомлений.

Поэтому портал сохраняет смысл и через неделю, и через несколько месяцев после публикации.

У каждого посетителя своё состояние в PHP-сессии. При наступлении нового календарного дня базовое демо автоматически создаётся заново относительно новой даты.

Кнопка **«Сбросить демо»** позволяет вручную вернуть исходное демонстрационное состояние.

## Deployment

Для этой проектной версии предусмотрен **отдельный deployment**, подключённый именно к репозиторию `Anuta10/php-bitrix-project-sandbox`.

Поддерживаются два варианта:

- **Timeweb Cloud App Platform** — основной публичный стенд;
- **Render** — отдельный резервный / международный стенд.

После создания нового сервиса его фактический URL нужно добавить в раздел **Live Demo** выше.

Основной workflow:

`git push → GitHub Actions → deployment`
