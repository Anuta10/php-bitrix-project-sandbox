# Короткий сценарий демонстрации

Это не обязательная последовательность для пользователя. Файл нужен как шпаргалка, если хочется быстро показать основные функции на интервью.

## Телефонный справочник

1. Открыть «Сотрудники».
2. Нажать букву `М` — в списке должны остаться только фамилии на «М».
3. Ввести `bdfy` — поиск исправит раскладку и найдёт Ивана.
4. Ввести `продаж` — совпадения подсветятся в должности или подразделении.
5. Очистить поиск и нажать «Показать ещё» — новые строки добавятся без перезагрузки.

## Дни рождения

1. Открыть список и сравнить прошедшую карточку, «Сегодня» и будущую дату.
2. Открыть календарь периода и выбрать несколько дней.
3. Добавить отдел в избранное и настроить напоминание.
4. Открыть пример письма.
5. Нажать «Поздравить», выбрать открытку/стикер и добавить текст.

## Календарь: сначала обычная встреча

1. Открыть «Календарь».
2. Создать встречу и **не выбирать** «Сопровождение связи».
3. Встреча появится в календаре, но связанной задачи у неё не будет.
4. В техническую очередь такое событие тоже не попадает.

Этот шаг важен: он показывает, что автоматизация не срабатывает на каждую встречу подряд.

## Календарь → «Сопровождение связи» → задача

1. Создать ещё одну встречу, например «Совещание с региональными подразделениями».
2. Отметить **«Сопровождение связи»**.
3. В появившемся поле написать, что нужно подготовить: видеосвязь, экран или подключение удалённых участников.
4. Сохранить встречу. В демо один шаг фоновой обработки запускается сразу, поэтому возле **«Задачи»** появляется красный счётчик `1`.
5. Открыть «Задачи» — связанная карточка один раз помечена как **«Новая»**, а счётчик сбрасывается.
6. Вернуться в календарь и перенести встречу на день. Та же задача обновится, возле «Задачи» снова появится `1`, новой карточки не будет.
7. Добавить к встрече комментарий, например «Добавьте подключение второго удалённого участника». Маркер появляется снова, а в задаче будет видно и сам комментарий.

Так основной сценарий понятен без технического экрана: действие в календаре сразу даёт визуальный результат в задачах.

## Сценарий с временной ошибкой

При создании встречи с выбранным «Сопровождением связи» раскрыть «Технический сценарий для демонстрации» и включить ошибку первой попытки.

1. После сохранения открыть «Как работает автоматизация» — первая попытка уже будет отмечена как неудачная.
2. Нажать «Повторить».
3. Нажать «Обработать одну» — задача создастся со второй попытки, а возле «Задачи» появится красный маркер.

Так удобно показать, зачем служебная работа вынесена из пользовательского запроса в фоновую очередь, не превращая саму очередь в отдельный пользовательский модуль.


## Наглядный маркер обновления задачи

В обычном показе техническую очередь открывать не обязательно. После события с выбранным «Сопровождением связи» обработка демо-заявки выполняется сразу, а рядом с пунктом **«Задачи»** появляется красный счётчик. Он показывает количество задач с непросмотренными изменениями.

Хорошая последовательность для показа:

1. Создать встречу с «Сопровождением связи» — возле «Задачи» появляется `1`.
2. Открыть задачи — новая карточка один раз помечена как **«Новая»**, счётчик сбрасывается.
3. Добавить комментарий к встрече — снова появляется `1`, а карточка при следующем открытии отмечена **«Новый комментарий»**.
4. Перенести встречу — та же задача получает статус **«Обновлена»**. Дубликат не создаётся.

Если одна задача изменилась несколько раз до просмотра, счётчик остаётся `1`. Это ближе к обычному интерфейсу: он показывает непросмотренные задачи, а не внутреннее количество операций синхронизации.

Страница **«Как работает автоматизация»** остаётся для технического разбора: там видны фоновые операции, журнал и сценарий повторной обработки при демо-ошибке.
