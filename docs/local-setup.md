# Локальный запуск и размещение

## Самый быстрый запуск

Из корня проекта:

```powershell
php -S 127.0.0.1:8080 -t public public/router.php
```

После запуска открыть:

`http://127.0.0.1:8080`

Остановить сервер можно сочетанием `Ctrl+C` в том же терминале.

## Docker

Если удобнее запускать проект в контейнере:

```bash
docker compose up --build -d
```

После этого открыть `http://localhost:8080`.

Остановка:

```bash
docker compose down
```

## Проверки

Перед публикацией:

```powershell
php tests/run.php
php bin/check.php
```

## Как ведут себя данные

Изменяемое состояние хранится в PHP-сессии, поэтому база данных для этой версии не нужна и действия одного посетителя не влияют на другого.

Базовые даты формируются относительно текущего дня. Если посетитель вернулся в тот же браузер уже на следующий день, демо-состояние пересоберётся автоматически, чтобы дни рождения, встречи и сроки снова выглядели актуально.

Кнопка «Сбросить демо» вручную возвращает чистое состояние, также рассчитанное относительно сегодняшней даты.

## Перед публичным размещением

Для публичного демо лучше использовать HTTPS и отдельный поддомен. Внешняя почта и реальные мессенджеры не подключены: все уведомления остаются внутри песочницы.
